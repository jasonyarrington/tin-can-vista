The reading layout for a post: title, meta line, an opening paragraph, headings, links, photos and a pull quote.

Wrap the whole post in `aw-prose`. It caps the line at 65 characters and sets 16px text on 26px leading. Use `aw-prose__lead` on the first paragraph only. Photos go in `figure` with a small `figcaption` beneath, at full column width with no frame or filter. Pull quotes use `blockquote` between two `hairline` rules, not a side bar. Links take the `action` color and stay underlined.
