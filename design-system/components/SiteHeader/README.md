The top and bottom of every page: a solid rust header band with the typeset site name, two or three nav links and the Light / Dark / System switcher, and a solid steel footer band.

The name is set in the stencil display face, with no logo mark. Text on the band is `on-band-rust`; text on the footer is `on-band-steel`. Mark the current page with `aria-current="page"`, which underlines it. The switcher (`aw-theme`) is three icon buttons, a sun for Light, a moon for Dark and a monitor for System. Each has an `aria-label` and a `title`, and `aria-pressed` marks the current choice; the icons are inline 16px SVG outlines drawn in `currentColor`. The site's script the site's script sets `data-theme` on `<html>` for Light and Dark, and removes it for System so the OS setting decides. Keep nav to three links so the header wraps to at most two rows on a phone.
